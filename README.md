Forecasts how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day, 19 November 2026 (UTC), as five quantiles per hour — learned from the launch-day shapes of past big console launches that unlocked at midnight local time, anchored on the launch's own first hour. See MODEL.md for the method and its leave-one-out validation (mean pinball loss about 0.22, versus about 0.34 for the persistence baseline).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
